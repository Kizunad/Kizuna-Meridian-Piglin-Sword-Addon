# 流金剑

功法谱列出上卷「软刃」和下卷「流金」。创造栏或命令可取得 `meridian_piglin_sword:upper_scroll` 和 `meridian_piglin_sword:lower_scroll`。学过上卷才能用下卷卷轴，一张下卷教会「缠」和「流金」。

上卷「绕」「抖」「弹」可用剑施展。默认仅金剑属于软剑，整合包可扩展 `#meridian_piglin_sword:soft_blades`。硬剑用「绕」会被盾挡，每式末击磨损两点。下卷两式需要软剑、真炁境和已开的两条手经、一条足经。

「流金」运气后持续十秒。本书记在握剑手上的打击穿盾，每击额外磨损一点，并在命中部位的皮肤上附加三成热伤。握剑手每秒受到半点皮肤伤害。火免和抗火能护住皮肤。淋雨、入水、换剑或换手会转为三十秒「淬硬」，期间软剑按硬剑处理。干燥处持剑到流金自然结束，可继续用软剑施式。
