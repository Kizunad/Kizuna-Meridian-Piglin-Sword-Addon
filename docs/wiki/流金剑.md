# 流金剑

功法谱列出上卷「软刃」和下卷「流金」。创造栏或命令可取得 `meridian_piglin_sword:upper_scroll` 和 `meridian_piglin_sword:lower_scroll`。学过上卷才能用下卷卷轴，一张下卷教会「缠」「流金」「泼金」。

堡垒遗迹的桥、藏宝室、疣猪兽棚和普通箱均有 5% 几率额外开出上卷。成年修士猪灵易货时有 2% 几率额外给上卷。玩家击杀学全下卷的类人生物时，有 5% 几率取得下卷。出生持软剑的金肤猪灵和黑僵僵尸猪灵学上卷，金骨猪灵和毛僵僵尸猪灵学上下卷。猪灵僵化时按原道行重建尸身，并按转化时带来的兵器定卷。

上卷「绕」「抖」「弹」可用剑施展。默认仅金剑属于软剑，整合包可扩展 `#meridian_piglin_sword:soft_blades`。硬剑用「绕」会被盾挡，每式末击磨损两点。下卷三式需要软剑、真炁境和已开的两条手经、一条足经。

「缠」起手半秒后，软剑盘上对方持兵的前臂。双方各锁住参与牵制的手，能在三格内移动。目标前臂的出力系数达到施放者的 1.5 倍会反拉，令施放者踉跄。没有持兵前臂或带「铸金」的目标无法缠住。

剑刃盘上时先割一记，持缠中每半秒割一下，共四下。两秒半后，剑从原先那条前臂抽回，斩伤最重。抽回后半秒内接「绕」，起手缩短一半。换剑、越距、打断、死亡、卸载或主动清除任一端都会解开双方，余下的割击随即停止。「缠住」与「持缠」在背包显示各自的图标和说明，牛奶和图腾保留这两条状态。

「流金」运气后持续十秒。本书记在握剑手上的打击穿盾，每击额外磨损一点，并在命中部位的皮肤上附加三成热伤。握剑手每秒受到半点皮肤伤害。火免和抗火能护住皮肤。淋雨、入水、换剑或换手会转为三十秒「淬硬」，期间软剑按硬剑处理。干燥处持剑到流金自然结束，可继续用软剑施式。

「泼金」须在流金期间起手。起手六成秒，释放时消耗所选手的整叠热剑，挥空也会结束流金。创造玩家保留物品。正面四格、六十度内的目标被热金泼到，挂金八秒；被泼到的出力组织动作变迟。金壳遇水仍在，到时在各自脚下落两粒金，一把剑总计最多九粒。

学会泼金的类人和尸修在生命低于三成、当前敌人进入扇区时优先泼出热剑。尸修从尸丹付费。一条命只能泼出一次，起手被打断仍可再试。生命门槛可在生人配置 `meridian-humanoid-brain.toml` 的 `[response].splash_health_ratio` 调整。
